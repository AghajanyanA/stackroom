# Stackroom

A small 3D physics room. Drop spheres, boxes, and cylinders, then stack them, bounce them, and throw them around.

## Run

```bash
npm install
npm run dev
```

The app listens on port 8080.

- Sphere, Box, and Cylinder drop shapes. Hold a button to rain more.
- Drag a shape to move it. Drag empty space to orbit the room.
- Gravity and Bounce update the live simulation.
- Tower drops a leaning stack. Clear empties the room.
- Keys: `1` `2` `3` drop, `T` tower, `C` clear, `R` reset the camera.
